```bash
npx skills add 1weiho/skills
```

## Skills

### cinematic-shot

https://github.com/user-attachments/assets/5eb24118-af70-4985-b558-aea73294e180

Shoots software UI like a film: a sequence of steep, oblique close-ups of the interface floating on a dark or light stage, with a razor-thin focal plane, a slow camera drift, and hard cuts on the action, ending on one line of copy and a still logo. It also shoots the same look as single stills for hero images, social cards, and posters. It covers the look and the edit, and leaves the rendering stack to the agent.

Try: "Make a cinematic launch video for our new search feature." or "Shoot a hero image and a social card of our new search feature."

```bash
npx skills add 1weiho/skills --skill cinematic-shot
```
